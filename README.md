# Mosabber Ahmed Bapon — Portfolio

Personal portfolio site. Live at **https://mosabberuddin.github.io**

- Plain static site (React + Vite), no backend.
- The published site is the `docs/` folder (GitHub Pages: branch `main`, folder `/docs`).
- To edit: change `src/` (content lives in `src/portfolio-data.ts`), then run `npm install && npm run build` to refresh `docs/`.
